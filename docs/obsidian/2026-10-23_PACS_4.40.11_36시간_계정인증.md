# PACS 4.40.11 — 계정별 36시간 인증 유지

## 확정 규칙과 구현

사용자 확정: **36시간 경과 또는 최초 인증 PC 종료 시 재인증**. 자정 기준 ‘1일 1회’로 계산하지 않는다.

| 항목 | 처리 |
| --- | --- |
| 최초 로그인 | 기존 PACS 서버의 ID/PW 확인 후 공동인증서를 확인하고 인증 서버 DB에 계정/PC/인증서를 연결 |
| 다른 PC 로그인 | 같은 PACS 서버·ID·PW에서 도출한 계정 조회 키로 유효 상태 확인. PACS 서버 ID/PW 확인도 매번 수행 |
| 최대 수명 | 인증서 검증 시각부터 36시간. 인증서 자체 만료가 더 빠르면 그때까지. 조회·유지 신호로 연장하지 않음 |
| 최초 PC 확인 | Windows 보조 프로그램이 20초마다 유지 신호. 90초 끊기면 종료·절전·연결 단절로 판정 |
| 정상/강제 종료 | 정상 보조 프로그램 종료는 종료 요청. 전원 차단·강제 종료는 90초 유예 후 해제 |
| 재시작 | 실행별 bootId 및 메모리의 원본 유지 권한을 복원하지 않아 재인증 필요 |
| 다른 PC 권한 | 상태 조회만 가능. 최초 PC의 유지 신호를 대신 보내거나 만료 시각을 연장할 수 없음 |
| 로그인 화면 | 입력한 ID/PW의 인증이 유효하면 인증서 버튼 회색·비활성. 경과/잔여 시간 표시, 입력 변경 시 이전 상태 해제 |
| 판독 승인 | 서버의 현재 인증서 유효·폐지 상태와 최초 PC 연결을 확인한 뒤 승인 요청 기록 |
| 비밀번호 처리 | PACS PW는 기존 PACS 서버/로컬 보호 저장소에서 처리. 인증 서버에는 PW·인증서 PW·개인키를 보내지 않음 |
| 호환 | 기존 PACS 3.40.10의 2시간 S256/HMAC 규격 유지. 4.40.11의 명시적 활성화만 36시간 적용 |

계정·PC 메타데이터는 `PACS_REPORTED`이며 인증 서버가 PACS ID/PW를 직접 검증했다는 뜻이 아니다. 인증 상태 조회 키는 PBKDF2-HMAC-SHA256으로 도출하며 서버에는 그 해시만 저장하고 PC에는 암호화해 저장한다. 상세 계약은 [[PACS_36시간_계정인증_연동]] 참조.
