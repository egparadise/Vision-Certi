# 관리자와 의사의 화면 흐름

antigravity는 인증·서명 처리를 설명할 수 있는 한국어 관리 UI를 구현한다. 정상 의사는 로그인 MFA 이후 문서를 확인하고 한 번 클릭해 승인한다. 위험 재인증, 서명 생성, 증거 수집, 병원 전송은 각각 구분해 보여준다.

## 화면 목록

| 화면 | 사용자 | 주요 동작·표시 | 완료 기준 |
|---|---|---|---|
| 로그인 | 모든 사용자 | MFA, 세션 만료 복귀 | 성공·실패·한도·재시도 표시 |
| 운영 대시보드 | 기관 관리자·운영자 | 서명 처리량, 전송 대기, 만료 알림 | 기관별 범위 명확 |
| 기관·권한 | 플랫폼·기관 관리자 | 기관 상태, 의사 소속·역할 | 타기관 데이터 미노출 |
| 의사 검증 | 신원 검증자 | 근거, 면허, 소속, 승인·반려 사유 | 근거 없는 승인 방지 |
| 판독문 목록 | 의사·기관 관리자 | 검사 참조, 버전, 상태 | 민감 식별정보 최소화 |
| 판독문 상세 | 지정 의사 | 동일 PDF 열람, 버전·기관 확인 | 열람 오류면 승인 차단 |
| 승인 화면 | 지정 의사 | 최종 판독·서명, 필요 시 Step-up | 연타·중복 전송 방지 |
| 정정 이력 | 권한 사용자 | 원본·새 버전·사유·각 서명 | 원본 편집 UI 없음 |
| 인증서 | CA 운영자·의사 | 발급·갱신·폐기·만료 | 사유와 이중 승인 상태 |
| 전송 큐 | 기관 관리자 | QUEUED/ACKED/재시도/실패 | 서명 완료와 전송 성공 구분 |
| 감사 | 감사자 | 기간·행위·대상·correlation 검색 | 열람 자체도 감사 |
| 검증 포털 | 권한 사용자 | 해시·서명·체인·시점·폐기·권한 | VALID/INVALID/INDETERMINATE 구분 |

공개 URL만 아는 비인증 사용자의 의료문서 조회는 제공하지 않는다. 증거 다운로드도 권한을 검사한다.

## 의사 서명 흐름

목록 → 문서 상세 → 지정 버전 PDF 확인 → 독립 승인 Origin → 최종 판독·서명 → 처리 상태 → 서명 완료·병원 전송 상태 순이다. 정상 세션에서는 추가 비밀번호 모달을 띄우지 않는다.

Approval 서비스의 화면은 별도 빌드·배포 경계에 둔다. 초기 모의 화면은 이 경계를 구현한 것으로 표시하지 않는다. 원격 의료기관 Origin으로 임의 returnUrl 리다이렉트를 허용하지 않는다.

Step-up이 끝났더라도 원래 문서 버전과 요청 만료를 다시 조회한다. 문서가 달라졌으면 새 내용을 열람하고 다시 승인한다. 사용자 승인 없이 자동 승인 재시도를 하지 않는다.

## 상태별 UX

- 승인 요청 전송 중 버튼을 비활성화하고 동일 작업의 Idempotency-Key를 유지한다.
- 응답 유실 시 상태를 조회한다. 기존 요청 결과 확인 전 새 키로 재승인하지 않는다.
- EVIDENCE_PENDING은 처리 중, RECONCILIATION_REQUIRED는 결과 확인 중으로 표시한다. 성공 아이콘을 먼저 보여주지 않는다.
- INDETERMINATE는 검증 불가·증거 부족으로 표시하며 실패 원인과 구분한다.
- 운영자의 전송 재시도와 의사의 재서명은 별도 동작이다. 전송 실패로 재서명을 유도하지 않는다.
- 기관을 바꾸면 진행 요청과 화면 캐시를 취소·초기화한다. 쿼리 키에 tenant를 포함한다.
- DRAFT 편집은 기존 시스템으로 안내한다. 새 프런트엔드에서 판독문 내용을 수정하지 않는다.

## 화면 기술 규칙

React·TypeScript·Vite, TanStack Query와 OpenAPI 타입을 사용한다. 색상은 남색·청록 중심, 표는 상태명과 아이콘을 함께 사용해 색에만 의존하지 않는다. 1280px 데스크톱과 768px 태블릿을 우선 검증하고 작은 화면에서도 핵심 동작을 제공한다.

입력 label·오류 연결·키보드 이동·focus 복원을 구현한다. 로딩·빈 목록·오류·권한 없음 화면을 모두 제공한다. 운영 환경에서 개발 tenant·역할 선택기를 노출하지 않는다.

토큰·의료문서·서명 payload를 localStorage/sessionStorage에 저장하지 않는다. PDF Blob URL은 화면 종료 시 revoke한다. 프런트 로그와 분석 도구에 문서 내용·개인정보를 보내지 않는다.

개발 mock 모드는 명시적으로 선택한다. 실제 API 오류가 발생했다고 mock 데이터로 자동 대체하지 않는다. 미구현 기능은 비활성화하고 준비 중이라고 표시한다. 개발 서명은 항상 의료용 효력 없음 문구를 표시한다.
