# 화면 도움말 `i` 정리

## 변경 내용

- 공통 도움말을 글자 버튼 대신 `i` 아이콘으로 표시한다. 화면 설명은 클릭하면 열리는 팝업에 두고, 닫기 버튼·바깥 클릭·Esc로 닫을 수 있다.
- 상단 운영 상태와 보안 경고에는 짧은 상태·경고 건수만 남긴다. 서명 백엔드, 저장소, 임상 사용 제한 사유와 경고 코드는 각 `i`에서 확인한다. 서버 상태 확인 실패 시 임상 사용 중지를 계속 명시한다.
- 대시보드에서 고정으로 표시하던 `IN_MEMORY`·`MOCK-HMAC-SHA256` 안내를 제거했다. 실제 `/v1/runtime/capabilities` 및 대시보드 응답으로 저장소·서명 방식을 표시한다.
- 지표 카드와 서명·전송 상태 표는 간결한 한국어 제목을 사용하고, 해설을 `i`로 옮겼다. 카드 내 팝업이 잘리지 않도록 펼침 상태의 레이어를 조정했다.
