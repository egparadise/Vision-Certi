설치 프로그램 다운로드

사용할 Windows PC에서 프로그램을 내려받아 설치해 주세요.

SaintView PACS 4.40.12

최초 공동인증 후 최대 72시간 동안 같은 계정으로 다른 PC에서도 로그인합니다. 최초 인증 PC가 종료되거나 인증이 만료되면 다시 인증합니다.

PACS 설치 파일 다운로드
Windows 64비트 · 약 165 MB · 함께 사용할 PC에 모두 설치해 주세요.

상단 인증 배지에 마우스를 올리면 인증 여부와 종료까지 남은 시간을 확인할 수 있습니다. 24시간부터 주황색, 48시간부터 빨간색과 재인증 경고를 표시합니다.

  1. PACS를 종료한 뒤 내려받은 설치 파일을 실행합니다.
  2. 설치 후 기존 ID/PW로 로그인하고 공동인증서를 확인합니다.
  3. 최초 인증 PC를 켜 둔 상태에서 다른 PC에 같은 ID/PW로 로그인합니다.
