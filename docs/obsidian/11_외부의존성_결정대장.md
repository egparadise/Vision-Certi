# 외부 의존성과 설계 결정

확정된 구현 기본값과 운영 전에 외부에서 받아야 할 자료를 분리한다. 공급자가 미정이어도 mock·계약·UI 개발은 가능하지만 실제 운영 통합 완료는 선언하지 않는다.

## 외부 자료와 차단 조건

| ID | 책임자 | 필요한 자료·결정 | 개발 중 대체 | 운영 차단 |
|---|---|---|---|---|
| EXT-001 | 인비즈 연동 담당 | Cloud Care 제품·버전, API/SSO, PDF·검사 ID, 병원 ACK, PACS 시험계정 | 합성 문서·REST 모의 병원 | 실제 병원 전송·SSO·정정 동기화 |
| EXT-002 | 인비즈 보안·구매 | HSM 모델·SDK·지원 알고리즘·TPS·승인 결속·운영자 권한·복구 | 명시적 mock, 필요시 SoftHSM | 실제 서명과 단독 통제 주장 |
| EXT-003 | 인비즈 구매·보안 | 실명·SMS 공급자, 발신 등록, 비용·한도·test account | 가상 OTP·본인확인 | 실명 확인·MFA 운영 |
| EXT-004 | 인비즈 보안 | TSA 공급자·신뢰체인·SLA·nonce 정책·장기 보존 | 모의 TSA | 신뢰 시각 증거 |
| EXT-005 | 인비즈 PKI 담당 | 자체 CA 운영 제품, CP/CPS, 루트 신뢰계약, CRL/OCSP URL·키 의식 | 개발 체인·mock 상태 | 인증서 발급·폐기·병원 신뢰 |

실제 API 문서나 프로젝트 파일을 추가로 받으면 인비즈가 지정한 범위만 분석하고 민감정보를 계획 문서에 복사하지 않는다.

## 개발 기본값

Access 5분, 유휴 15분, 절대 세션 8시간, OTP 3분·5회·재전송 60초, 서명 요청 10분, 승인 실행 120초, PDF 20MiB, 전송 최대 10회·24시간, 멱등성 기록 24시간. 값은 정책 버전으로 관리하고 과거 서명 당시 정책을 보존한다.

병원 요구가 확정되면 이 표, API 예제, 테스트 fixture, 환경 설정을 함께 바꾼다. 보존기간은 임의 기본값으로 확정하지 않으며 계약 전 운영 객체 자동 삭제는 구현하지 않는다.

## 변경 기록 양식

날짜 / ADR 또는 EXT ID / 기존 결정 / 새 결정 / 근거·승인자 / 영향받는 API·DB·화면·시험 / 마이그레이션·운영 조치 / 완료 증거를 기록한다. 새로운 결정으로 기존 서명의 검증 정책을 덮어쓰지 않는다.
